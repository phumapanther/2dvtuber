# 2DVtuber

ตัวละคร 2D VTuber / PNGTuber ที่วาดเองทั้งหมด พร้อมระบบริกบนเว็บ (`rig_studio/`) สำหรับใช้ไลฟ์

Hand-drawn original 2D VTuber / PNGTuber characters, with a browser-based rig (`rig_studio/`) for streaming.
