=== Tiger PNGTuber — วิธีใช้ ===

[วิธีที่แนะนำที่สุด: ใส่ใน OBS ตรง ๆ (Browser Source + ตัวช่วย)]
ข้อดี: โมเดลไม่หยุดขยับแม้เปิดเกม/สลับจอ, พื้นโปร่งใสไม่ต้อง chroma key,
หัวหันตามเมาส์ได้ทั้งเครื่อง (แม้กำลังเล่นเกมอยู่), ปากขยับตามไมค์ตลอด

ต้องมี: Python + ไลบรารี (ลงครั้งเดียว):
    pip install websockets sounddevice numpy

ขั้นตอน:
1. ดับเบิลคลิก "เปิดตัวช่วยOBS.bat" — เปิดค้างไว้ตลอดการสตรีม
   (หน้าต่างดำเล็ก ๆ อ่านไมค์+เมาส์ส่งให้โมเดล / ปิดเมื่อเลิกสตรีม)
2. OBS → Sources → + → Browser
   - ติ๊ก "Local file" → เลือกไฟล์ index.html ในโฟลเดอร์นี้
   - Width 1920, Height 1080, FPS 60
   - เอาติ๊กออก "Shutdown source when not visible"
3. เสร็จ! พื้นหลังโปร่งใสอัตโนมัติ ปรับขนาด/ตำแหน่งได้เลย
   (หน้าจะรู้เองว่าอยู่ใน OBS แล้วซ่อนแถบเครื่องมือให้)

ปรับความไวไมค์ในโหมด OBS: เอาติ๊ก Local file ออก แล้วใส่ URL แทน:
    file:///C:/Users/watch/Downloads/2DVtuber/rig/index.html?obs&sens=12
    (sens ยิ่งมาก ปากยิ่งไวต่อเสียง ค่าปกติ 8)

[วิธีสำรอง: เปิดใน Chrome + Window Capture]
1. ดับเบิลคลิก index.html → กด 🎤 เปิดไมค์ → เลือกพื้นเขียว → F11 เต็มจอ
2. OBS: Window Capture + ฟิลเตอร์ Chroma Key
ข้อจำกัด: ห้ามย่อหน้าต่าง Chrome และเมาส์ถูกอ่านเฉพาะตอนชี้ในหน้าเว็บ
(ถ้าเปิดตัวช่วยไว้ด้วย เมาส์+ไมค์จะใช้ของทั้งเครื่องแทน อาการนี้ก็หาย)

[ย้ายไปเครื่องอื่น]
ก๊อปโฟลเดอร์ rig ทั้งโฟลเดอร์ เครื่องปลายทางต้องมี Chrome/Edge
และถ้าจะใช้วิธี OBS + ตัวช่วย ให้ลง Python (python.org ติ๊ก Add to PATH)
เปิดตัวช่วยOBS.bat จะติดตั้งไลบรารีให้เองอัตโนมัติในครั้งแรก

[แก้ปัญหา ตัวช่วยไม่ทำงานใน OBS]
1. หน้าต่างดำของตัวช่วยขึ้น "ModuleNotFoundError: No module named 'numpy'"
   → เปิด เปิดตัวช่วยOBS.bat เวอร์ชันล่าสุด มันจะ pip install ให้เอง
     (หรือพิมพ์เอง: python -m pip install numpy websockets sounddevice)
2. เช็คไฟสถานะ: โหลด Browser source ใหม่ → มุมล่างซ้ายของโมเดลจะมีจุดกลม 25 วินาทีแรก
   จุดเขียว = ต่อตัวช่วยติดแล้ว / จุดแดง = ยังหาตัวช่วยไม่เจอ (ตัวช่วยยังไม่เปิด?)
3. หน้าต่างตัวช่วยต้องขึ้น ">> โมเดลเชื่อมต่อแล้ว ✓" ตอน OBS โหลดโมเดล
   และพอพูดต้องมีแถบ "เสียง: ####" วิ่ง — ถ้าไม่วิ่ง = อ่านไมค์ผิดตัว
   ดูรายชื่อไมค์ที่มันพิมพ์ตอนเปิด แล้วรัน: python helper.py --dev <เลขไมค์ที่ใช้จริง>
4. ใน OBS เอาติ๊กออก "Shutdown source when not visible" (สำคัญ)
5. อยากเห็นตัวเลขดีบักในโมเดล: ใส่ URL แบบมี ?obs&debug (เอาติ๊ก Local file ออก):
   file:///D:/พาธของคุณ/rig/index.html?obs&debug
6. พื้นหลังไม่ใสใน OBS → อัปเดต index.html เวอร์ชันล่าสุด (แก้แล้ว ไม่ต้องใส่ Custom CSS)
7. แก้ไฟล์ index.html แล้วแต่ใน OBS ยังเป็นแบบเก่า (เช่น ตาไม่ขยับ) → OBS แคชหน้าไว้
   คลิกขวาที่ Browser source → Properties → กดปุ่ม "Refresh cache of current page" → OK
   (หรือปิด-เปิด OBS ใหม่ก็ได้)

[แถบเครื่องมือ (เปิดในเบราว์เซอร์ เลื่อนเมาส์ชิดขอบล่าง)]
- 🔗 ตัวช่วย: สถานะการเชื่อมต่อกับ helper
- 🎤 เปิด/ปิดไมค์ (ใช้เมื่อไม่ได้เปิดตัวช่วย) + แถบระดับเสียง
- ความไว: ปรับการตอบสนองปาก (จำค่าอัตโนมัติ)
- พื้นหลัง: เขียว/น้ำเงิน/เทา/ขาว (สำหรับวิธี chroma key)
