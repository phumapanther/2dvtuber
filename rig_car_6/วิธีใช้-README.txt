=== Chibi WhiteTiger PNGTuber (car6) — วิธีใช้ ===

[ตัวละครตัวที่ 6 — เสือขาว chibi หัวโต (2026-08-20)]
- ประกอบจากไฟล์ PSD ที่ผู้ใช้จัดวางเอง:
  ../2D_Craracter_Chibi/Model_PNG_Tuber (1536x2304 = 1.5x ริก, 12 กลุ่ม mask)
  + ปาก 5 แบบ / แก้มบลัช 2 สถานะ (crop พื้นขาวในโฟลเดอร์เดียวกัน)
- ดีไซน์เป็น bust: หัวโต + หู + ลำตัวช่วงไหล่ ไม่มีหาง
- ระบบ:
  * หัวโยกตามเมาส์รอบโคนคอ + idle drift + หายใจ
  * ตาดำมองตามเมาส์ (ใน mask เนื้อตาขาว ตาโตเลื่อนได้ไกล)
  * กะพริบอัตโนมัติ (เปลือกตาหลับจาก PSD)
  * หูสะบัดเอง + สะบัดตอนเริ่มพูด
  * ปากขยับตามเสียง 6 สถานะ: หุบ(เส้นเดิมบนหน้า) -> แง้ม -> ยิ้มเปิด
    -> เปิด+ลิ้น -> อ้ากว้าง -> โอ (ตะโกน)
  * แก้มบลัช: นิ่ง = วงนุ่ม, พูดต่อเนื่อง = เข้มขึ้นมีเส้น (ขึ้นไว คลายช้า)
- สร้างเลเยอร์ใหม่:  python bake_chibi.py
  (ต้องมี: pip install psd-tools aggdraw)
- ขยับตำแหน่งปากทั้งชุด: แก้ MOUTH_POS ใน index.html แล้ว F5 — ไม่ต้อง bake

[วิธีใช้กับ OBS]

   1920x1080 FPS 60, เอาติ๊กออก "Shutdown source when not visible"
3. หลังแก้ไฟล์ กด "Refresh cache of current page" 1 ครั้ง
