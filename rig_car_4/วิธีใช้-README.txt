=== WhiteTiger PNGTuber (car4) — วิธีใช้ ===

[ตัวละครตัวที่ 4 — เสือขาวเสื้อแทร็ค (2026-08-19)]
- ชิ้นส่วนทั้งหมดมาจาก ../2D_Craracter_4/ ที่ผู้ใช้จัดตำแหน่งเสร็จแล้ว
  (PNG เต็มผืน 1024x1536 ทุกไฟล์ — bake ไม่ตัดแต่งรูป แค่ก๊อป/ครอปหูหาง)
- ความสามารถ:
  * หัวหันตามเมาส์ + ตาดำ (ตาแมว) มองตามเมาส์ใน mask ตาขาว
  * กะพริบตาอัตโนมัติ (ใช้ภาพ ตาปิด.png สลับทันทีแบบอนิเมะ)
  * หูสะบัดเองอัตโนมัติ + ขยับตามการหันหัว / หางแกว่งเองอัตโนมัติ
  * ปากขยับตามเสียง 3 ระดับ (เบา/กลาง/ดัง) และสลับรูปสระ A/B/C
    อัตโนมัติขณะพูด — ใช้ปากครบทั้ง 9 แบบที่เตรียมไว้
- สร้างเลเยอร์ใหม่:  python bake_car4.py
  (แก้อาร์ต → แก้ไฟล์ใน ../2D_Craracter_4/ แล้วรัน bake ใหม่ อย่าแก้ car4_*.png)

[วิธีใช้กับ OBS]
1. เปิด "เปิดตัวช่วยOBS.bat" ค้างไว้ (ใช้ร่วมกับโมเดลอื่นได้ ตัวเดียวพอ)
2. OBS → Browser Source → Local file → เลือก index.html ในโฟลเดอร์นี้
   Width 1920, Height 1080, FPS 60, เอาติ๊กออก "Shutdown source when not visible"
3. พื้นหลังใสอัตโนมัติ / หลังแก้ไฟล์ กด "Refresh cache of current page" 1 ครั้ง

[วิธีสำรอง] เปิดอวตาร.bat (พอร์ต 8934) → เปิดไมค์ → พื้นเขียว → OBS Window Capture

[โหมดทดสอบ]
index.html?demo    = ขยับเองอัตโนมัติ
index.html?blink=1 = ตาหลับค้าง (0..1)
index.html?debug   = ตัวเลขดีบัก + สระปากปัจจุบัน
index.html?sens=12 = ความไวไมค์ (ปกติ 8)
