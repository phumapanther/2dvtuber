[ตัวละครตัวที่ 3 — ต้นไม้หน้าคนในโพรง (2026-08-18, เลย์เอาต์ผู้ใช้ rev 2)]
- เลย์เอาต์/โครงสร้างชิ้นส่วนมาจากโฟลเดอร์ ชิ้นส่วน/ ที่ผู้ใช้จัดใน PSD
  เลเยอร์อวาต้าต้นไม้ (แคนวาส 1536x2304 = 1.5 เท่า — พิกัด ÷1.5)
  โครงสร้างเด่น: ลำต้นด้านหน้าเจาะรูโพรง หน้าลอดผ่านรู มีผนังโพรงมืดรองหลัง
  และใบหน้ามีเปลือกตาหลับปั้นในตัว (กะพริบ = ซ่อนชุดตาเปิด ไม่มีเลเยอร์ตาหลับแยก)
- ปาก 5 สถานะ + ใบไม้ร่วง ยังตัดจากแผ่น AI ใน ../2D_Craracter_3/ (แผ่น xp5x9b)
- ความสามารถ:
  * ตาดำมองตามเมาส์ (อยู่ใน mask เบ้าตา ไม่หลุด) + กะพริบตาอัตโนมัติ
  * หน้าในโพรงขยับนุ่ม ๆ ตามเมาส์ + หายใจ
  * พุ่มใบ (หลัง+หน้าลำต้น) เอนตามเมาส์เหมือนโดนลม
  * แอปเปิ้ล 3 ลูกแกว่งตามพุ่ม + เด้งตอนเริ่มพูด
  * ใบไม้ร่วงเองอัตโนมัติตลอดเวลา (แทนหูแมว/หางของโมเดลก่อน)
    และร่วงพรูหนึ่งชุดตอนเริ่มพูด
  * ปากขยับตามเสียงไมค์ 5 สถานะ (เส้นปกติ→A→I→U→O)
- ไฟล์เลเยอร์ = car3_*.png  สร้างใหม่:  python bake_car3.py
  (อย่าแก้ car3_*.png มือ — ค่าตำแหน่ง/ขนาดอยู่หัวไฟล์ bake_car3.py
   โพรงบนลำต้นถูกหาอัตโนมัติ ปรับโซนค้นหาที่ HOLLOW_ZONE)

[วิธีใช้กับ OBS]
1. เปิด "เปิดตัวช่วยOBS.bat" ค้างไว้ (ตัวเดียวใช้ร่วมกับโมเดลอื่นได้ พอร์ต 8765)
2. OBS → Browser Source → Local file → เลือก index.html ในโฟลเดอร์นี้
   Width 1920, Height 1080, FPS 60, เอาติ๊กออก "Shutdown source when not visible"
3. พื้นหลังใสอัตโนมัติ / หลังแก้ไฟล์ กด "Refresh cache of current page" 1 ครั้ง

[วิธีสำรอง] เปิดอวตาร.bat (พอร์ต 8933) → เปิดไมค์ → เลือกพื้นเขียว → OBS Window Capture

[โหมดทดสอบ]
index.html?demo   = ปาก/ต้นไม้ขยับเอง
index.html?blink=1 = ตาหลับค้าง (0..1)
index.html?debug  = ตัวเลขดีบัก + จำนวนใบไม้
index.html?sens=12 = ความไวไมค์ (ค่าปกติ 8)
