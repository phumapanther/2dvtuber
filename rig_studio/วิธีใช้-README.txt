=== Rig Studio — ศูนย์รวมอวตารทุกตัว (วิธีใช้) ===

รันที่เดียว เปลี่ยนที่เดียว: อวตารทุกตัว (car1-car6) อยู่ในโปรแกรมเดียว
สลับตัวได้จากเมนูมุมล่าง ไม่ต้องเปิดโฟลเดอร์ทีละริกอีกแล้ว

──────────────────────────────────────────
[เริ่มใช้ 3 ขั้น]
1. ดับเบิลคลิก "เปิดอวตาร.bat"
2. เอาเมาส์ชิดขอบล่าง → แถบเครื่องมือโผล่:
   [เลือกอวตาร] [🔗สถานะตัวช่วย] [🎤ไมค์] [มิเตอร์เสียง] [🎭อีโมต] [☰เมนู]
3. อยากได้อะไรเพิ่ม เปิด ☰ เมนู — ทุกอย่างจัดหมวดไว้ให้:
   ความไวไมค์ · ความแรงอีโมต · ความขี้เล่น (ซ้าย=สุขุม ขวา=ซน) · พื้นหลัง
   · 🧬อวตาร · 📸กล้อง · ✨ลูกเล่น · 🎬อัดคลิป · 🎁โดเนท · 📺OBS · 🛠ขั้นสูง

[โฟลเดอร์]
rig_studio/
  index.html          ← เอนจินเดียว ใช้กับทุกอวตาร
  avatars.js          ← รายชื่ออวตาร (เพิ่มตัวใหม่มาเพิ่มบรรทัดที่นี่)
  avatars/car1/       ← รูปชิ้นส่วน + avatar.js (โครงริก) + layout.js (ค่าที่เซฟ)
                        + emote_N.png (รูปอีโมต ถ้ามี) + sounds/ (เสียงเฉพาะตัว ถ้ามี)
  sounds/             ← เสียงกลางใช้ร่วมทุกอวตาร (ดูรายชื่อไฟล์ด้านล่าง)
  vendor/             ← ไลบรารีจับหน้า+ทำ GIF (โหลดมาเก็บแล้ว ใช้ออฟไลน์ได้ ห้ามลบ)
  helper.py           ← ตัวช่วย OBS: ไมค์+เมาส์+คีย์บอร์ดทั้งเครื่อง + สะพานคำสั่ง HTTP

──────────────────────────────────────────
[✅ เช็คลิสต์: สิ่งที่คุณเตรียมเองได้ (ใส่ปุ๊บระบบใช้ให้ทันที)]

1) เสียงประกอบอีโมต — วางไฟล์ .mp3 ในโฟลเดอร์ sounds/ ตามชื่อนี้เป๊ะ ๆ:
     emote_1.mp3  พยักหน้า        emote_6.mp3  หมุนตัว
     emote_2.mp3  ส่ายหน้า        emote_7.mp3  สั่น
     emote_3.mp3  ตกใจ            emote_8.mp3  หลับ/ตื่น
     emote_4.mp3  เอียงคอ         emote_9.mp3  ตื่นเต้น
     emote_5.mp3  เด้งดีใจ        donate.mp3   ตอนมีโดเนท
   - ไม่ต้องครบทุกไฟล์ มีไฟล์ไหนเล่นไฟล์นั้น ไม่มีก็เงียบเฉย ๆ
   - อยากให้อวตารบางตัวเสียงไม่เหมือนใคร: สร้าง avatars/ตัวนั้น/sounds/
     แล้ววางไฟล์ชื่อเดียวกัน (ระบบหยิบของตัวนั้นก่อน ไม่มีค่อยใช้ของกลาง)
   - ปิด/เปิดเสียงทั้งหมด: ☰ เมนู → 🔊

2) รูปอีโมต (หน้าตกใจ ตาหัวใจ ฯลฯ) — วางไฟล์ .png ในโฟลเดอร์อวตารตัวนั้น:
     avatars/car1/emote_3.png  = รูปโผล่ตอนอีโมต "ตกใจ" ของ car1
     avatars/car1/emote_8.png  = รูปโชว์ค้างตลอดที่หลับ (เช่น ตาปิด >_<)
   - แคนวาส 1024x1536 เท่าชิ้นส่วนอื่น พื้นหลังโปร่งใส
     วาดตรงไหนของแคนวาส รูปก็โผล่ตรงนั้น (ขยับตามหน้าอวตารให้เอง เฟดเข้า-ออกให้เอง)
   - อยากบังตา/ปากเดิม: ระบายทึบทับตำแหน่งนั้นได้เลย
   - ทำทีละไฟล์ได้ ใส่เพิ่มเมื่อไหร่ก็ใช้ได้ทันที (รีเฟรชหน้า)

3) แจ้งเตือนโดเนท — กดทดสอบได้ที่ ☰ เมนู → 🎁 ทดสอบแจ้งเตือน
   (แบนเนอร์ + คอนเฟตติ + อวตารตื่นเต้น + เสียง donate.mp3)
   ต่อกับของจริง (ต้องออนไลน์ + เปิดตัวช่วย OBS ค้างไว้):
   - ทางที่แนะนำ: โปรแกรม Streamer.bot (ฟรี) รับอีเวนต์โดเนท/ซับ/follow
     จาก Twitch/YouTube แล้วตั้ง action ยิง HTTP GET มาที่:
       http://127.0.0.1:8766/donate?name=%user%&amount=%amount%&msg=%message%
   - Stream Deck: ปุ่ม "System → Website" ใส่ URL เดียวกัน (ใส่ชื่อ/ยอดเองได้)
   - โปรแกรมไหนก็ได้ที่ยิง HTTP ได้ ใช้ได้หมด — ทดสอบด้วยเบราว์เซอร์ก็ได้:
     เปิด http://127.0.0.1:8766/donate?name=ทดสอบ&amount=100
   - สั่งอีโมตจากภายนอกก็ได้: http://127.0.0.1:8766/emote?n=3

[🎯 ปาของ]  ☰ เมนู → 🎯 ปาของ (🍅 มะเขือเทศ / 💖 หัวใจ / 🪨 ก้อนหิน)
  คีย์ลัดในหน้าเว็บ: T (มะเขือเทศ)  H (หัวใจ)  R (ก้อนหิน)
  ของจะลอยจากขอบจอเข้าหาตัว พอชนปุ๊บ อวตารเอียง/สะเทือนไปทางที่โดนปา
  + หู/หาง/ผมสะบัดแรงตามน้ำหนักของ (ก้อนหินแรงสุด)
  - เสียงตอนชน (ถ้ามี): sounds/throw_tomato.mp3 · throw_heart.mp3 · throw_rock.mp3
  - รูปเอง (แทนอีโมจิ): เติม throwables:{tomato:"ไฟล์.png",...} ใน avatar.js ของตัวนั้น
  - สั่งจากแชท/Stream Deck (ต้องเปิดตัวช่วย OBS): http://127.0.0.1:8766/fx?type=tomato
    ผูกกับคำสั่งแชท เช่น !throw ใน Streamer.bot ได้เหมือนโดเนท

[อีโมต]  ปุ่ม 🎭 หรือกดเลข 1-9 ในหน้าเว็บ
         หรือ Ctrl+Alt+เลข จากทั้งเครื่อง-แม้อยู่ในเกม (ต้องเปิดตัวช่วย OBS)
    1 พยักหน้า  2 ส่ายหน้า  3 ตกใจ  4 เอียงคอ  5 เด้งดีใจ
    6 หมุนตัว   7 สั่น      8 หลับ/ตื่น  9 ตื่นเต้น

[ลูกเล่นอัตโนมัติ]  (เปิด/ปิดใน ☰ เมนู)
- 🙂 จับหน้าจริง: หันหน้า/ก้มเงย/เอียงหัว/อ้าปาก/กะพริบตา → อวตารทำตามแบบกระจก
  กดปุ่มตอนนั่งหน้าตรง (เฟรมแรก = ท่ากลาง) · ทำงานออฟไลน์ (ไลบรารีอยู่ใน vendor/)
  ต้องเปิดผ่าน เปิดอวตาร.bat หรือใน OBS เท่านั้น
- 📷 จับความเคลื่อนไหว (โหมดเบา): อวตารหันมองตามที่ขยับ โบกมือแรง = หู/หางสะบัด
- 🎵 โยกตามจังหวะเพลง: จับ beat จากเสียงที่ไมค์ได้ยิน
- 😴 หลับเอง: เงียบ+นิ่ง 45 วิ → ตาปรือ คอตก Zzz ลอย (ก่อนหลับจะเบื่อ:
  เหลือบมอง/เอียงคอ/หูสะบัด/หาว/ถอนหายใจ สลับกันเองเป็นระยะ) มีเสียง/ขยับปุ๊บตื่นทันที
- ของแถม: สะบัดเมาส์เร็ว = ผม/หางโดนลม · คลิก = หูสะบัด · พิมพ์ = ตัวเด้งตามจังหวะ

[🎬 อัดคลิป]  (☰ เมนู — ไม่ต้องมี OBS ก็อัดได้)
- 🎬 อัดวิดีโอ: กดแล้วเลือกแชร์ "แท็บนี้/หน้าต่างนี้" → กดอีกทีเพื่อหยุด
  ได้ไฟล์ .webm ลงโฟลเดอร์ Downloads (เอาไปตัดต่อ/แปลงต่อได้)
- 🖼 GIF 4 วินาที: จับภาพสั้น ๆ เป็นไฟล์ GIF แชร์ได้เลย
- เคล็ดลับ: อยากได้พื้นเขียวไว้ทำ chroma key เลือกพื้นหลังเขียวก่อนอัด

[OBS]
1. เปิด "เปิดตัวช่วยOBS.bat" ค้างไว้ (ไมค์+เมาส์+คีย์ลัด+สะพานโดเนท)
2. OBS → Sources → + → Browser → ติ๊ก Local file → เลือก index.html โฟลเดอร์นี้
   หรือดีกว่านั้น: ☰ เมนู → 📋 ก็อปลิงก์สำหรับ OBS แล้ววางเป็น URL
   (ลิงก์จะพกอวตาร+ค่าที่จัด+โหมดที่เปิดอยู่ เช่น จับหน้า/จังหวะ ไปด้วย)
3. Width 1920 Height 1080 FPS 60, เอาติ๊กออก "Shutdown source when not visible"

[จัดตำแหน่ง / แต่งอวตาร]  (☰ เมนู → ✏️)
- ลากบนจอ = ย้ายชิ้น · ล้อเมาส์ = ย่อขยาย · หมุน/หน้า-หลังมีปุ่มในแผง
- "ขยับ" เลือกรูปแบบต่อชิ้น: นิ่ง/ตามเมาส์/พารัลแลกซ์/พลิ้ว/ดุ๊กดิ๊ก/แกว่ง/เด้ง/ลอย/โชว์ตอนพูด
  + สไลเดอร์ "แรง"
- 🔄 เปลี่ยนรูปชิ้น / ➕ เพิ่มรูปใหม่ (ก็อปไฟล์ลงโฟลเดอร์อวตารก่อน แล้วค่อยเลือก)
- 🧩 ติ๊กเปิด/ปิดการแสดงผลทีละชิ้น (เช่น ถอดสูท car5)

[พรีเซ็ท]
- 💾 บันทึกพรีเซ็ท = จำชุดแต่งไว้หลายแบบ สลับได้
- 🈳 เปล่า = ซ่อนทุกชิ้น เหลือชื่อช่อง (สีแดง = ส่วนขยับ) ไว้ใส่รูปใหม่ทีละช่อง

[สำคัญ: เซฟค่าให้ติดไปทุกที่]
ค่าที่แต่งปกติจำเฉพาะเบราว์เซอร์นี้ — กด ☰ เมนู → 📁 เซฟค่าลงโฟลเดอร์อวตาร
(ได้ไฟล์ layout.js) แล้วเปิดจากที่ไหนก็ได้ค่าตรงกัน รวมถึงชิ้นที่ซ่อน
เซฟครั้งแรกแล้วจะเซฟตามอัตโนมัติทุกครั้งที่แก้

[เพิ่มอวตารตัวใหม่]  — มีปุ่มให้แล้ว: ☰ เมนู → 🧬 ➕ สร้างอวตารใหม่
  (หรือเลือก "➕ เพิ่มอวตารใหม่…" ท้ายเมนูเลือกอวตาร)
1. ตั้งชื่อโฟลเดอร์ (อังกฤษ) + ชื่อที่โชว์
2. เลือกว่าจะ "โคลนโครง" จากตัวไหน (ระบบก็อป avatar.js + รูปให้ครบ เปิดติดทันที)
   หรือเว้นว่าง = เริ่มเปล่า แล้วไปกด ➕ เพิ่มรูปใหม่ ในโหมด ✏️ เอง
3. เลือกโฟลเดอร์ rig_studio ตอนที่ระบบขอ — เสร็จ เปิดตัวใหม่ให้เลย
4. ทำเป็นตัวของตัวเอง: ใช้พรีเซ็ท 🈳 เปล่า แล้ว 🔄 ใส่รูปของคุณทีละช่องสีแดง
   (หมายเหตุ: การโคลนต้องเปิดผ่าน เปิดอวตาร.bat และใช้ Chrome/Edge)

วิธีมือ (ทางเลือก): สร้าง avatars/ชื่อใหม่/ ใส่รูป + avatar.js แล้วเพิ่มบรรทัดใน avatars.js

[ลิงก์พารามิเตอร์]

- ผ่านตัวช่วย (ทุกโปรแกรมบนเครื่อง): http://127.0.0.1:8766/emote?n=..  /donate?..  /fx?type=..
