[วิธีที่แนะนำที่สุด: ใส่ใน OBS ตรง ๆ (Browser Source + ตัวช่วย)]
ต้องมี Python + ไลบรารี (ลงครั้งเดียว):  pip install websockets sounddevice numpy

1. ดับเบิลคลิก "เปิดตัวช่วยOBS.bat" — เปิดค้างไว้ตลอดการสตรีม
   (ถ้าเปิดตัวช่วยของ rig ตัวแรกอยู่แล้ว ไม่ต้องเปิดซ้ำ — ใช้ตัวเดียวกันได้
    ทั้งสองโมเดล ผ่านพอร์ต 8765 เดียวกัน)
2. OBS → Sources → + → Browser
   - ติ๊ก "Local file" → เลือกไฟล์ index.html ในโฟลเดอร์นี้ (rig_car_2)
   - Width 1920, Height 1080, FPS 60
   - เอาติ๊กออก "Shutdown source when not visible"
3. เสร็จ! พื้นหลังโปร่งใสอัตโนมัติ

ปรับความไวไมค์ในโหมด OBS: เอาติ๊ก Local file ออก แล้วใส่ URL แทน:
    file:///C:/Users/watch/Downloads/2DVtuber/rig_car_2/index.html?obs&sens=12
    (sens ยิ่งมาก ปากยิ่งไวต่อเสียง ค่าปกติ 8)

[วิธีสำรอง: เปิดใน Chrome + Window Capture]
1. ดับเบิลคลิก index.html (หรือ เปิดอวตาร.bat) → กด 🎤 เปิดไมค์ → เลือกพื้นเขียว → F11
2. OBS: Window Capture + ฟิลเตอร์ Chroma Key

[แก้ปัญหา]
- เหมือน rig ตัวแรกทุกข้อ — ดู ../rig/วิธีใช้-README.txt หัวข้อ [แก้ปัญหา]
- จุดเขียวมุมล่างซ้าย = ต่อตัวช่วยติด / จุดแดง = ยังไม่เจอตัวช่วย
- แก้ index.html แล้ว OBS ไม่เปลี่ยน → คลิกขวา Browser source → Properties →
  "Refresh cache of current page"
- แก้รูป/rebake แล้วภาพไม่เปลี่ยน → index.html ใส่ตัวกันแคชรูปให้แล้ว:
  ทุกครั้งที่โหลดหน้าใหม่จะดึงรูปล่าสุดเสมอ — ในเบราว์เซอร์แค่ปิด-เปิดใหม่
  หรือใช้ เปิดอวตาร.bat / ใน OBS กด "Refresh cache of current page" ครั้งเดียว

[ปรับตำแหน่งปากเอง — ง่ายสุด ไม่ต้อง bake]
เปิด index.html ด้วย Notepad หาบรรทัด:
    const MOUTH_POS = [504, 686];
เลขแรก = ซ้าย-ขวา (มาก = ขวา), เลขสอง = สูง-ต่ำ (มาก = ลง) หน่วยพิกเซล
แก้เลข → เซฟ → รีเฟรชหน้า (F5 หรือ Refresh cache ใน OBS) เห็นผลทันที
เส้นปากปิดกับปากพูดทั้ง 4 แบบจะย้ายตามกันเองทั้งชุด

[โหมดทดสอบ]

index.html?blink=0.5 = ค้างตาที่หลับครึ่งเดียว (ไว้เช็คแนวเปลือกตา)
