=== WhiteTiger Skin PNGTuber (car5) — วิธีใช้ ===

[ตัวละครตัวที่ 5 — เสือขาวร่างไม่ใส่เสื้อ (2026-08-19)]
- ร่างเปลือยของโมเดลตัวที่ 4 ชิ้นส่วนจาก ../2D_Craracter_5/
  (PNG เต็มผืนจัดตำแหน่งแล้วทุกชิ้น — bake ไม่ตัดแต่งรูป)
- จุดต่างจากตัวอื่น: "หัวกับตัวนิ่ง" ตามดีไซน์ — ขยับเฉพาะ:
  * ตาดำมองตามเมาส์ (ใน mask ตาขาว) + กะพริบอัตโนมัติ (ตาหลับ.png)
  * หูสะบัด/ลอยเองอัตโนมัติ
  * หางแกว่งเองอัตโนมัติ + สะบัดตอนเริ่มพูด
  * ปากขยับตามเสียง 3 ระดับ x สลับสระ A/B/C อัตโนมัติ (ปากครบ 9 แบบ)
- สร้างเลเยอร์ใหม่:  python bake_car5.py
- แมพปาก: ปาก.png=เบาA, (1)=เบาB, (2)=เบาC, (3)=กลางA, (4)=กลางB,
  (5)=กลางC, (6)=ดังA, (7)=ดังB, (8)=ดังC

[วิธีใช้กับ OBS]
1. เปิด "เปิดตัวช่วยOBS.bat" ค้างไว้ (ใช้ร่วมกับโมเดลอื่นได้)
2. OBS → Browser Source → Local file → index.html ในโฟลเดอร์นี้
   1920x1080 FPS 60, เอาติ๊กออก "Shutdown source when not visible"
3. หลังแก้ไฟล์ กด "Refresh cache of current page" 1 ครั้ง

- เลเยอร์ชุดอยู่บนสุดของโมเดล เปิด/ปิดได้ 3 ทาง:
  1. ปุ่ม 🥼 ชุด ในแถบเครื่องมือ (จำค่าอัตโนมัติ)
